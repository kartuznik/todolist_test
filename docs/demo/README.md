# Демо

Снимков в этом каталоге пока нет. Ниже сцены, которые владелец добавит файлами PNG. Это список ожидаемых кадров, не сами изображения.

- `ru-desktop.png` — русский экран на широком окне: список задач и три карточки (Календарь, Приоритеты, Аналитика) с бейджем «СКОРО».
- `en-desktop.png` — тот же экран после переключения на английский: заголовок Get Things Done и бейдж SOON.
- `ru-mobile.png` — русский экран около 375px: фильтры могут переноситься, карточки стоят столбиком.

Файлы класть рядом с этим README: `docs/demo/ru-desktop.png`, `docs/demo/en-desktop.png`, `docs/demo/ru-mobile.png`.
